# WeatherScape

Type any place — a city, a landmark, a mountain, a beach — and WeatherScape shows it as a 3D scene with its current weather.

- **Live data** (no API key): Open-Meteo weather, marine and flood models; OpenStreetMap Nominatim place search; USGS earthquakes; GDACS disaster alerts. **Virtual mode** works offline.
- **6 scene types**, built procedurally: metropolis, town, village, tourist site, forest / national park, coast / harbour.
- **4 times of day** (night, morning, day, evening) from the real sun path, **6 weathers** (clear, cloudy, rain, snow, heavy rain, typhoon) with rain/snow particles, fog, wet and snow-covered surfaces, wind-bent trees, waves, lightning and thunder.
- **Special notices** (earthquake, tsunami, volcano, flood, wildfire, tropical cyclone, heat/cold wave, strong wind, heavy snow, fog) as messages, plus effects for eruptions, quakes, floods, tsunamis and wildfires. Any of them can be simulated.
- Korean / English UI (UI Toolkit, Noto Sans KR).

Unity 6000.6.3f1, URP. The scene `Assets/WeatherScape/Scenes/WeatherScape.unity` is generated by one editor command (`ws_setup_scene`) through the Unity CLI pipeline package.

See [Docs/BuildFromScratch.md](Docs/BuildFromScratch.md) (Korean) for the design, rules, commands and verification results.

Data: [Open-Meteo](https://open-meteo.com/) (CC BY 4.0), [OpenStreetMap Nominatim](https://nominatim.org/) (ODbL), [USGS Earthquake Hazards](https://earthquake.usgs.gov/), [GDACS](https://www.gdacs.org/), GloFAS via Open-Meteo. Font: Noto Sans KR (SIL OFL).
