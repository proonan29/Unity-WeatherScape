# WeatherScape — 장소별 날씨 장면 (처음부터 만드는 순서)

장소(도시·명소·산·해변 등)를 입력하면 **실제 기상 API(Open-Meteo)** 또는 **가상 데이터**로 현재 날씨를 구하고,
그 장소에 맞는 **6가지 장면**(대도시 / 중소도시 / 시골마을 / 관광지 / 숲·국립공원 / 바다·항구) 중 하나를 절차적으로 만들어
**4가지 시간대**(밤 / 아침 / 낮 / 저녁)와 **6가지 날씨**(맑음 / 구름 / 비 / 눈 / 폭우 / 태풍)로 보여 줍니다.
화산·지진·홍수·쓰나미·산불 같은 특이사항은 화면 위쪽 메시지로 표시하고, 일부는 장면 효과(분화, 흔들림, 침수, 해일, 연기)로도 보여 줍니다.
CleanerBot·WeldingBot·ThemePark와 같은 방식(Unity CLI + Pipeline 패키지, `ws_` 명령, 명령 하나로 씬 재생성)으로 만들었습니다.

- 환경: Windows, Unity 6000.6.3f1 (URP, `com.unity.template.urp-blank`, Forward+), Unity CLI 1.0.0-beta.11
- 경로: `D:\UnityAIProjs\DigitalTwin\WeatherScape`
- 패키지 추가: `com.unity.pipeline` 0.8.0-exp.1 (`[CliCommand]` → `unity command ws_*`)
- 작업 순서: C# 작성 → `AgentTools\dryrun.ps1`(컴파일 확인) → `Refresh.cs` → `ws_*` 명령 → `ws_capture`/`ws_matrix` 스크린샷 → git 커밋
- 처음 만들기: `unity projects create WeatherScape --path D:\UnityAIProjs\DigitalTwin --editor-version 6000.6.3f1 --template com.unity.template.urp-blank --no-cloud`
  → manifest에 `com.unity.pipeline` 추가 → Editor 열기 → `ws_setup_scene`

## 2. 장소 → 장면 분류 (`Classify.Scene`)
1. 내장 목록에 있으면 그 장면(예: 경주 → 관광지, 하회마을 → 시골마을, 해운대 → 바다)
2. 지오코더 분류
   - 바다/항구: beach, coastline, bay, harbour, marina, pier, lighthouse, cape, island …
   - 숲/국립공원: national_park, protected_area, nature_reserve, peak, volcano, wood, forest, valley, waterfall …
   - 관광지: tourism/*, historic/*, theme_park, castle, palace, temple, museum, tower …
3. 인구: 100만 이상 대도시(해안이면 대도시 + 바다), 5만 이상 중소도시, 그 미만 시골 — 5만 미만·5만 이상이라도 **해안이면 바다/항구**
4. 인구를 모르면 이름(해변·국립공원·궁 …)과 place 종류(village/hamlet → 시골, city → 중소도시)
5. 해안 여부: Open-Meteo Marine API에 파고 값이 있으면 해안
- 실측 예: 청주→중소도시, 목포·포항→바다/항구, 단양(도담삼봉)→관광지, Waikiki Beach→바다, Taj Mahal→관광지, Yosemite→숲, Interlaken(인구 5,504)→시골, Chicago(274만)→대도시

## 3. 날씨·시간대 판정
- 날씨: 태풍 = 평균풍 ≥ 17.2 m/s 또는 돌풍 ≥ 25 m/s + 비 / 눈 = WMO 71–77, 85–86 또는 강설 / 폭우 = 65, 67, 82, 95–99 또는 ≥ 7.6 mm/h / 비 = 51–67, 80–82 / 구름 = 코드 ≥ 2 또는 구름 ≥ 60% / 그 외 맑음. 뇌우(95–99)는 번개, 가시거리 < 1 km는 안개
- 시간대: 아침 = 일출 30분 전 ~ 일출 3시간 후, 저녁 = 일몰 1.5시간 전 ~ 일몰 45분 후, 그 사이 낮, 나머지 밤
  - 시간대를 직접 고르면 대표 시각: 아침 = 일출 + 50분, 낮 = 13시, 저녁 = 일몰 − 45분, 밤 = 23시
- 계절: 위도·현지 날짜(남반구 6개월 이동, |위도| < 23°는 여름) → 나뭇잎·논밭·잔디 색(봄 벚꽃, 가을 단풍, 겨울 마른 색)

## 5. 날씨 연출
- 하늘: 태양 고도에 따라 낮 파랑 → 노을 주황 → 밤 남색(별·달), 구름량 0.12(맑음)~1(폭우·태풍), 바람 방향으로 흐름
- 조명: 해/달 방향광(밤에는 달빛 0.55), 구름이 많으면 그림자·직사광 약해지고 환경광 회색, 밤에는 반사광 낮춤
- 안개(지수²): 맑음 0.00042, 구름 0.0006, 비 0.00095, 눈 0.0012, 폭우 0.0015, 태풍 0.0019, 짙은 안개 0.0028. 밤에는 도시 불빛 때문에 지평선이 주황빛
- 표면: 비 0.65 / 폭우 0.9 / 태풍 1 → 어둡고 반짝이는 젖은 표면, 눈 → 지붕·땅·도로 0.85 흰색 덮임
- 파티클: 비 3,500~22,000개/s(바람에 기울어짐), 눈 2,500~9,000개/s(난류), 태풍 잔해, 화산재
- 바람: 나무 휨·흔들림(돌풍), 파고 0.25 + 2.6·바람^1.5 m(실측 파고가 있으면 반영), 물거품, 차량 감속(태풍 35%)
- 번개(뇌우·폭우·태풍): 2.5–9초 간격 하늘 번쩍임 + 보조광 + 번개 줄기 + 거리만큼 늦은 천둥 소리
- 밤: 창문(8×8 무작위 점등 텍스처)·가로등·차량 전조등·등불·경고등 발광, Bloom

## 7. UI
- 왼쪽 패널: 장소 검색(Enter), 검색 결과(2개 이상일 때), 바로 가기 12곳 / 현재(이름·지역·현지 시각·날씨·기온·체감·습도·바람·구름·가시거리·강수·파고·일출/일몰, 장면 판정 이유, 표시 중인 시간대·날씨·계절, 출처) / 데이터(실시간·가상·새로고침) / 표시(장면·시간대·날씨 자동 또는 직접 선택, 가상 재해 5종, 모두 자동) / 설정(언어, 소리, 자동 회전)

- 실시간 데이터를 못 받으면 가상 데이터로 자동 전환("오프라인 – 가상 데이터를 사용합니다")

## 8. CLI 명령 (`AgentTools\ws.ps1 <명령>`)
- 장면: `ws_setup_scene [--place 서울]`, `ws_setup_font`
- 데이터(씬 변경 없음): `ws_lookup --query <장소> [--pick n] [--lang en]` (검색 결과·분류·실시간 날씨·특이사항), `ws_classify --queries "a,b,c"`
- 표시(에디트/플레이): `ws_show --place <장소> [--mode virtual|live] [--scene Coast] [--phase Night] [--weather Typhoon] [--hazards Volcano,Flood] [--yaw 도]`
  - 자동은 `auto` (주의: `-1`은 CLI가 옵션으로 해석)
- 플레이 모드: `ws_search --query <장소>`, `ws_set [--scene/--phase/--weather auto|이름] [--hazards a,b|none] [--mode live|virtual] [--lang ko|en]`, `ws_status`
- 스크린샷(UI 없이 카메라만): `ws_capture --name <파일>`, `ws_matrix --scene <장면>`(행: 밤·아침·낮·저녁, 열: 맑음·구름·비·눈·폭우·태풍), `ws_hazard_sheet --scene <장면>`(없음·화산·지진 / 홍수·쓰나미·산불)
- 도구: `dryrun.ps1`(파일마다 using을 자기 namespace 안으로 옮겨 합친 뒤 컴파일 확인), `snap.ps1 <이름> [w] [h] screen`(UI 포함), `focus_unity.ps1`, `Particles.cs`(파티클 상태)
